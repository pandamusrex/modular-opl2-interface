# modular-opl2-interface
Integrate the OPL2 Audio Board from Cheerful Electronics with a modular synthesis setup for a retro drum machine and more

## Notes / Hooking It Up
* Depends on OPL2 library by DhrBahksteen

* OPL2 board is connected as follows:
 * Pin  8 - Reset
 * Pin  9 - A0
 * Pin 10 - Latch
 * Pin 11 - Data
 * Pin 13 - Shift

* Modular interface - CV in (0-5V) on
 * Pin 2 - Bass
 * Pin 3 - Snare
 * Pin 4 - HiHat
 * Pin 5 - Crash
 * Pin 6 - Cowbell
 * Pin 7 - Claves
